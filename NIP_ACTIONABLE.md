
NIP-XXX
======

Tracking Actionable Items
-----------

`draft` `optional`

This NIP defines new structures for actionable items,
such as tasks, projects and gantt chart entries.
It is based on the following NIPs:
- 10 (marked `e` tags) for task references
- 34 (Git Stuff) for tasks and states
- 52 (Calendar Events) for scheduling

## Making Items Actionable
An Actionale Item is a single, flexible event type to accomodate a diversity of productivity systems and approaches.

For implementations compatible with this NIP,
any event can become an actionable item
through publishing of a state update (Kind 1630-1633)
referencing this event
with an `e` or `a` tag.

Typically this is applied to text notes (Kind 1)
as well as git issues (Kind 1621).
However, only the latter are implicitly considered actionable items
(equivalent to issuing state 1630 open at creation),
and any Kind 1 events referencing them are interpreted as description elements,
but only for people with write access to the original task.

The content of the referenced event
is taken as the title of the actionable item ("Task").
Comments to tasks can be made as git replies (Kind 1622)
by any person.

## Time-Tracking

### Format

The format uses a parameterized replaceable event kind `10100`.

The `.content` of these events is required as a title of the actionable item.

The list of tags are as follows:
* `d` (required) universally unique identifier (UUID). Generated by the client creating the Actionable Item.
* `a` (optional, repeated) reference tag to kind `31922` or `31923` calendar event 
* `p` (optional, repeated) 32-bytes hex pubkey of assignee, optional recommended relay URL, and participant's role in the meeting
  -> Ownership?
* `t` (optional, repeated) hashtag to categorize calendar event
* `r` (optional, repeated) references / links to web pages, documents, video calls, recorded videos, etc.

## (Actionable) Item State

* `a` (required) reference tag to kind `10100` actionable item or `31922` or `31923` calendar event
